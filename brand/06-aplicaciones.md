# 6. Aplicaciones

«La marca en acción»: piezas reales que mantienen la jerarquía, la paleta y el tono del Tutor. Cada
pieza usa el imagotipo en su versión adecuada (negativo sobre navy, positivo sobre claro).

|-------|-------------|
| **Rollup / stand** | Banner vertical 85×200 cm para eventos · logo en negativo sobre navy con textura topográfica. |
| **Letrero / señalética** | Señalización corporativa con el imagotipo (fachada e interiores). |
| **Credencial institucional** | Carné/gafete para colaboradores y eventos · identidad sobre navy con logo en negativo. |
| **Banner de webinar** | Anuncio para pantallas y RRSS. |
| **Camiseta institucional** | Merchandising · logo en negativo sobre navy. |
| **Estuche de CD / media kit** | Empaque de material multimedia · portada con imagotipo sobre navy. |
| **Taza corporativa** | Merchandising de oficina y eventos · logo en negativo sobre navy. |
| **Tarjeta de presentación** | Papelería ejecutiva · imagotipo y datos de contacto. |

## Reglas para nuevas aplicaciones
- Respetar **área de seguridad** (½x) y versiones oficiales del logo.
- Fondo navy → logo en **negativo**; texto naranja sobre navy → variante clara `#FFBBA1`.
- Usar **una** textura de fondo por pieza; no mezclar varias texturas.
- Mantener proporción de color 60/30/10 (navy/azul/naranja).
- Tipografía Nunito para todo texto; wordmark solo en el logo.
