# 7. Gobernanza y uso

## Confidencialidad
El brandbook está marcado **«Documento confidencial — Prohibida su difusión»**. Este repositorio se
mantiene por decisión del propietario para consumo de IAs internas y del equipo. No difundir fuera
del contexto autorizado ni reutilizar los activos para terceros.

## Fuente de verdad y precedencia
1. **`/tokens/tokens.json`** → valores de diseño (colores, tipografía, radios). Máxima precedencia.
2. **`/brand/*.md`** → reglas y uso.
3. **`/pdf/Brandbook-Actuaria.pdf`** → referencia visual completa (40 páginas, A3 ×1.41).

Si hay conflicto, gana `tokens.json`. Si un valor no existe en el repo, **no es de marca**.

## Instrucciones para asistentes de IA
- No inventes colores, fuentes, claims ni valores estratégicos ausentes.
- Marca como **pendiente** lo que aquí figure como pendiente (p. ej. las letras de CREE/ACTÚA).
- Respeta las **reglas duras**: orden símbolo/wordmark, no recolorear el wordmark, naranja sobre
  navy con `#FFBBA1`, proporción 60/30/10.
- Al generar piezas, cita la sección de origen (`brand/0X-...md`).

## Versionado
- Versión actual del documento: **2026-07** (brandbook A3, 40 páginas).
- El PDF de este repo corresponde a esa versión.
- Cambios de marca se reflejan primero en el archivo Figma maestro y luego se sincronizan aquí.
