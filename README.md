# Brandbook Actuaria Consultores — edición legible por IA

> Fuente de verdad de la identidad de marca de **Actuaria Consultores**, estructurada para ser
> **consumida por asistentes de IA** (LLMs) y por personas. Todo el contenido normativo está en
> Markdown plano + tokens en JSON/CSS. El PDF es el entregable visual para humanos.

**Versión:** 2026-07 · **Formato maestro:** A3 apaisado (×1.41), 40 páginas · **Idioma:** español.

---

## Cómo usar este repositorio (para IAs)

1. Lee primero [`llms.txt`](./llms.txt) — índice compacto pensado para LLMs.
2. Para reglas de marca, entra a [`/brand`](./brand) (un archivo por tema).
3. Para valores exactos de diseño (colores, tipografía, radios), usa
   [`/tokens/tokens.json`](./tokens/tokens.json) — **es la fuente canónica de tokens**.
   Nunca inventes un color o fuente: si no está en `tokens.json`, no es de marca.
4. El PDF completo está en [`/pdf/Brandbook-Actuaria.pdf`](./pdf/Brandbook-Actuaria.pdf)
   (referencia visual; el texto normativo vive en el Markdown de este repo).

### Reglas de oro (resumen ejecutable)
- **Claim:** «Trazamos el camino juntos.»
- **Arquetipo:** El Tutor (El Sabio + El Cuidador) → tono de *mentor*: claro, riguroso, cercano.
- **Colores núcleo:** Navy `#151F47`, Azul `#3061AA`, Naranja `#DF5E2D` sobre neutro `#E8ECF4`.
- **Tipografía:** wordmark en *Lemon Milk*; sistema y cuerpo en **Nunito**.
- **Símbolo:** imagotipo del **velero**; el símbolo nunca va a la derecha del wordmark.
- **Metáfora rectora:** *cartas de navegación / mar de datos* — guía todo el sistema visual.
